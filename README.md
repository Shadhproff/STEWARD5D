# 🦠 STEWARD5D

An interactive web-based simulator designed to evaluate and improve healthcare professionals' (clinicians, pharmacists, and life scientists) knowledge of the **5 Ds of Antimicrobial Stewardship**. 

Developed as a capstone project for the **LUMINARI AMR Ambassadorship Program**.

---

## 🌟 Overview
Antimicrobial resistance (AMR) is a major global health threat driven largely by inappropriate antibiotic use. **STEWARD5D** provides an interactive learning environment where users work through realistic clinical scenarios, make structured stewardship decisions, and receive immediate educational feedback.

The application evaluates decision-making across the core **5 Ds**:
1. **Diagnosis** — Identifying the correct underlying pathology.
2. **Drug** — Choosing the most appropriate antimicrobial agent (or withholding when unnecessary).
3. **Dose** — Tailoring the correct dosage regimen.
4. **Duration** — Restricting therapy to the shortest effective timeframe.
5. **De-escalation** — Safely adjusting or stopping therapy based on clinical evolution.

---

## 🚀 Key Features
* **Interactive Clinical Scenarios:** Real-world case simulations (e.g., Acute Sore Throat, Uncomplicated Lower UTI).
* **Attempt Tracking & Scoring:** Evaluates choices and records score differentials between initial attempts and retries.
* **Database Integration:** Securely logs session metrics and participant responses to a MySQL database hosted via Clever Cloud.
* **Built with Python & Streamlit:** Fast, responsive web application interface designed for seamless accessibility.
